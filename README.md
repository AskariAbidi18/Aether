# Aether

> A modular AI runtime for building, orchestrating, and evaluating intelligent systems.

## Vision

Aether is an open-source AI runtime focused on understanding and building modern AI systems from first principles.

Rather than treating AI frameworks as black boxes, Aether incrementally implements and benchmarks the core components behind:

- Large Language Models
- Retrieval-Augmented Generation (RAG)
- Agent Systems
- Semantic Memory
- Model Routing
- Evaluation Pipelines
- Tool Execution
